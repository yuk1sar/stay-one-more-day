# ОСТАНЬСЯ ЕЩЁ НА ДЕНЬ

Одностраничный сайт поддержки: Vite + React + обычный CSS. Без UI-фреймворка и аналитики. Для добровольной отправки писем автору добавлена серверная функция Vercel.

## Запуск

Установите Node.js 22.12+ (или 24 LTS), откройте папку проекта в VS Code и выполните в терминале:

```sh
npm install
npm run dev
```

Откройте адрес, который покажет терминал (обычно http://127.0.0.1:5173).

Сборка для размещения: `npm run build`. Результат — папка `dist`. Локальная проверка сборки: `npm run preview`.

## Что внутри

- Письмо «Лично от автора» на RU / EN / AZ с широким коллажем и красной заключительной фразой. Тексты — `src/author.json`, изображение — `public/author-letter.png`.

- Переключатель RU / EN / AZ в шапке. Переведены разделы, действия, сообщения, подписи доступности и метаданные; язык сохраняется в localStorage. Заметка не переводится и не сбрасывается при смене языка.
- Карточка с запрошенной цитатой, русским переводом и ссылкой на QuoteFancy. Атрибуция указана по этому сайту; первоисточник не подтверждён.
- Hero с оригинальным сгенерированным xerox-артом, коллажная сетка, бумажные текстуры.
- Четыре переключаемых шага поддержки, доступные контакты помощи.
- Раздел «Как помочь близкому»: пять шагов поддержки по рекомендациям NIMH.
- Десятиминутный таймер: старт, пауза, продолжение, повтор. Учитывает реальное прошедшее время при смене вкладки, без звука. Перезагрузка сбрасывает таймер.
- Личная заметка до 3000 символов: явное сохранение в localStorage, восстановление после перезагрузки, подтверждение удаления, обработка недоступного хранилища. Несохранённый текст не переживает перезагрузку; браузер получает запрос предупредить о выходе.
- Адаптивная вёрстка, клавиатурная навигация, фокус, reduced-motion.

`src/main.jsx` — тексты и поведение. `src/style.css` — оформление. `public/art.png` — ключевой арт. Для замены картинки используйте этот путь и обновите alt-текст.

`src/en.json` и `src/az.json` — переводы; `src/support.json` — раздел помощи близкому; `src/ui.json` — метаданные и дополнительные подписи. Для обновления существующей публикации Vercel из папки проекта выполните `npx vercel --prod`.

Исходный сгенерированный арт из прошлого чата оказался недоступен; в проект включён новый оригинальный арт по описанию и доступному референсу. Шрифты Oswald и PT Mono загружаются с Google Fonts; при отсутствии сети используются системные шрифты. Записка, сохранённая себе, никуда не отправляется. Отдельная кнопка с согласием отправляет письмо автору в Telegram. Подключение описано в TELEGRAM.md. Доступ к localStorage не защищён от других пользователей того же устройства. Смена домена/порта или очистка данных меняет доступность заметки.
